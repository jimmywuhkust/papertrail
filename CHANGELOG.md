# Changelog

## 2.0.0 — 2026-08-24

- Rebuilt PaperTrail as a public, bilingual research product.
- Added local PDF extraction, DOI/RFC discovery, reference resolution, graph exploration, and missing-citation suggestions.
- Added ACM/IETF-aware search and a ten-year MobiCom, MobiSys, and SenSys radar.
- Replaced the unbounded force layout with a deterministic, capped citation map for stable performance.
- Added privacy and methodology pages, structured metadata, social sharing, sitemap, robots, and installable-app metadata.
- Added accessible loading, empty, error, keyboard, and reduced-motion states.
